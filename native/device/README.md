# LovyanGFX 装置層

`native/device/` は、NIF から渡された値を使って LovyanGFX を操作する C ABI / C++ 適合層です。
AtomVM の項解析や NIF 戻り値の作成は `native/` 側で行います。

## ファイルと担当

| ファイル | 担当 |
| --- | --- |
| `device.h` | NIF 層が使う公開 C ABI |
| `device_internal.hpp` | 内部宣言と共通処理 |
| `state.cpp` / `state_runtime.cpp` | 装置状態、対象解決、実行時のパネル・タッチ設定 |
| `control.cpp` | 初期化、終了、回転、明るさ、色深度 |
| `text.cpp` | 文字、フォント、カーソル、折り返し、倍率 |
| `primitives.cpp` | 基本図形 |
| `images.cpp` | JPEG、RGB565 画像 |
| `sprites.cpp` | スプライト・パレットの確保、転送、回転・拡大縮小 |
| `clip.cpp` | クリップ矩形 |
| `fonts/generated/` | 構築時に組み込む生成済みフォント |

## 所有権と検証

稼働中の LCD は単一実体です。初期化時に設定のスナップショットを受け取り、
不透明な所有者識別子で初期化・終了・寸法照会を解決します。
対象 `0` は LCD、`1..254` は明示的に確保したスプライトです。

この層では対象の存在、スプライトの確保状態、パレットの有無、画像の行幅と長さ、
回転・拡大縮小の引数など、装置側の条件を検証します。
NIF の項変換・操作番号の検証は持ち込まず、固定版 LovyanGFX への適合面を小さく保ちます。

外部の動作契約が変わる場合は [操作契約](../../docs/protocol.md) と生成物を更新してください。
全体の責務とデータの生存期間は [構成](../../docs/architecture.md) を参照してください。
